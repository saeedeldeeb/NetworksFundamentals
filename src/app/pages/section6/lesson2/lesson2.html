DNS (Domain Name System)

Every URL you type triggers a DNS query — one of the most frequently used protocols on the internet, yet almost entirely invisible to users. Without it, you'd be memorizing IP addresses to visit websites.

Why DNS Exists

IP addresses change frequently, servers use load balancing across many IPs, and nobody wants to remember 142.250.80.46 for Google. DNS maps human-readable names to IP addresses and abstracts all of that complexity away.

Every addressing system in networking needs a mapping layer — DNS is the internet-wide version of what ARP does on a local network:

Protocol Maps
ARP IP address → MAC address (local)
DNS Domain name → IP address (internet)

What DNS Abstraction Buys You

1
Load Balancing

One domain can return multiple IPs in round-robin. Clients pick one. Netflix used this for client-side load balancing in their early architecture.

2
IP Transparency

Server IP changes? Update the DNS record. Clients keep using the same domain — no reconfiguration needed on their end.

3
Geo DNS / CDNs

Cloudflare, Fastly, and CDNs serve different IPs based on client location. A user in India gets a nearby server; a user in the US gets a different one. Lower latency for everyone.

How Resolution Works

DNS is a distributed, hierarchical system — not one giant database. Resolution walks down the hierarchy: Root servers know TLD servers, TLD servers know authoritative servers, and authoritative servers know the actual IP.

DNS Resolvers

When you connect to a network, you get a resolver (usually your router). Popular public resolvers are hardcoded by IP — they must be, since using a domain would cause an infinite loop.

Security Problems

DNS is plaintext by default. Every domain you visit is sent unencrypted over UDP port 53. Your ISP sees every DNS query — they can log all domains you visit, block access to specific sites, or redirect queries entirely. HTTPS encrypts the content, but the DNS query revealing which domain you're visiting remains visible.
!
DNS Hijacking

An attacker becomes a fake authoritative server and responds with malicious IPs, redirecting users to phishing sites.

!
Cache Poisoning

An attacker floods the resolver with fake responses, guessing the transaction ID. If successful, the resolver caches the attacker's IP — and all future queries return it.

Encrypted DNS

Protocol Name Port Notes
DoT DNS over TLS 853 (TCP) Identifiable, admin-friendly
DoH DNS over HTTPS 443 (HTTPS) Blends with web traffic, controversial

DoH looks like normal HTTPS traffic — network admins can't distinguish DNS from web requests, which sparked debate about privacy vs. control. DoT uses a dedicated port (853) so it's easier to identify and manage, yet still encrypted. Adoption is around 20%.

Centralization risk: DNS is "decentralized" at the root/TLD level, but highly centralized at authoritative servers. When Facebook's authoritative name servers went down in 2021, their entire suite of services — Instagram, WhatsApp, Messenger — became unreachable worldwide, even though root and TLD servers were perfectly healthy.

Practical Tools

Key insight: DNS adds 7–8 UDP round trips before you can even start the TCP handshake. That's why DNS caching matters so much, why TTLs are carefully tuned, and why Node.js performs DNS lookups asynchronously via libuv — blocking on DNS would devastate throughput in a server handling thousands of connections.
